# Balíčky wireless

Nezměněné soubory z <https://download.mikrotik.com/routeros/>. Přibalené pro
práci na lokalitě bez internetu.

| soubor | pro |
|---|---|
| `wireless-7.23.7-arm64.npk` | nRAY 60G na RouterOS 7.23.7 |
| `wireless-7.24.5-arm64.npk` | nRAY 60G na RouterOS 7.24.5 |
| `wireless-7.23.7-arm.npk` | Cube 60G ac / LHG 60G / wAP 60G na 7.23.7 |
| `wireless-7.24.5-arm.npk` | Cube 60G ac / LHG 60G / wAP 60G na 7.24.5 |

Verze balíčku **musí** sedět s verzí běžícího RouterOS. Pro jinou verzi:

```
https://download.mikrotik.com/routeros/<verze>/wireless-<verze>-<arch>.npk
```

Soubory patří MikroTiku a platí pro ně jeho licenční podmínky.
